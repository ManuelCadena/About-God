# About God

Repositorio académico doctoral de investigación sobre Dios, Logos, Filosofía, Teología y Ciencia.
Autor: José Manuel Cadena Ortiz de Montellano.

## Estructura

| Carpeta | Contenido |
|---------|-----------|
| `00-META/` | Metadatos, inventario, changelog, créditos |
| `01-BOOK/` | Libro principal: *The God Equation* (preprint, resúmenes, versión en español) |
| `02-PROBABILITY-OF-GOD-MODEL/` | Modelo probabilístico de la existencia divina: papers, revisiones, figuras |
| `03-SCIENTIFIC-FOUNDATIONS/` | Bases científicas: Levin, Friston, Watson, Hoffman, Penrose |
| `04-FRAMEWORK-INTEGRATION/` | C2AI Framework, LOGOS HUMANO, La Gran Convergencia |
| `05-PAPERS-ACADEMIC/` | Papers académicos publicables |
| `06-LOGOS-AND-PHILOSOPHY/` | Filosofía del Logos, espacio platónico, emergencia, verdad, señal |
| `07-AMELIA-RUIZ-CONFERENCES/` | Transcripciones del canal Academia de Filosofía Pythagorica A.C. |
| `08-SOFTWARE-AND-MODELS/` | Código fuente de logoi-app, C2AI Framework y scripts |
| `09-ASSETS/` | Imágenes, figuras, videos |
| `10-ARCHIVE/` | Originales no clasificados y versiones de respaldo |

## Uso con LLMs

Todo el contenido está en Markdown plano con metadatos YAML frontmatter cuando aplica.
Los archivos `.docx` y `.pdf` originales permanecen intactos junto a sus conversiones `.md`.
Usa los `README.md` de cada carpeta para navegar y el `00-META/INVENTORY.md` para búsquedas.
