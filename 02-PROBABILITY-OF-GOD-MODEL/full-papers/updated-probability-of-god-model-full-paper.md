# Updated Coefficients Used in the Model

Using the point estimates justified in the previous section, the following coefficients were applied to the logistic regression model. Each coefficient reflects the evidential weight (in log-odds) that a given variable contributes to the probability that God exists, assuming a value of 1 for the presence of that evidence:

  --------------------------------------------------------------------------------------
  Variable                Description                            Coefficient (β)
  ----------------------- -------------------------------------- -----------------------
  FT                      Cosmological Fine-Tuning               +2.5

  MO                      Moral Objectivity                      +1.0

  CG                      Consciousness Gap                      +1.5

  RE                      Religious Experience                   +0.8

  EV                      Severity of Moral Evil (neutralized)   0.0

  BC                      Biological Complexity                  +1.5

  QM                      Quantum Metaphysical Indicators        +0.3

  MN                      Metaphysical Necessity                 +1.5

  β₀                      Intercept (prior neutrality)           0.0
  --------------------------------------------------------------------------------------

This means the total log-odds in favor of God's existence when all eight variables are considered as fully present in our actual world is:

logit(P) = 0.0 + 2.5 + 1.0 + 1.5 + 0.8 + 0.0 + 1.5 + 0.3 + 1.5 = 9.1

Converted to a probability:

P(God exists) = 1 / (1 + e\^(-9.1)) ≈ 99.99%

This outcome reflects the compounded weight of interdisciplinary evidences, with none of the variables contributing negatively after the reinterpretation of moral evil.
