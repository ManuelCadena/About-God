The God Equation — Prompt HeyGen v4 para high school

Versión pedagógica para estudiantes de high school. Lenguaje natural, ejemplos cotidianos, animación CGI 2D y 3D, voz en off sin avatar y texto en pantalla controlado carácter por carácter.

Regla central: una escena no debe parecer científica; debe enseñar una idea científica. La narración plantea una pregunta sencilla, la animación muestra qué cambia y el texto en pantalla nombra únicamente la idea que el estudiante necesita recordar.

1. Qué puede hacer HeyGen

CGI 2D determinista

Hyperframes convierte HTML, CSS, SVG y JavaScript en video. Sirve para texto exacto, diagramas, curvas, tablas, mapas, contadores y animaciones educativas. Es la opción correcta cuando importa que una palabra, un número o una fórmula aparezcan sin errores.

CGI 3D real

La guía oficial de Hyperframes recomienda pedir Three.js mediante el adapter cuando se necesita profundidad real, iluminación, sombras o movimiento de cámara. El 3D se usa para recorrer un espacio de posibilidades, una célula o un paisaje de estados; no para decorar.

2. Arquitectura visual para enseñar

Cada escena seguirá el mismo patrón: pregunta → ejemplo → cambio visible → idea para recordar. Los términos nuevos se explican antes de usarlos. Las oraciones habladas tendrán entre ocho y dieciséis palabras siempre que sea posible.

3. Contrato de texto en pantalla

CampoRegla cerrada
ContenidoSolo las cadenas escritas entre comillas después de TEXTO EXACTO.
OrtografíaCopiar carácter por carácter. No traducir, resumir, completar ni corregir automáticamente.
CantidadMáximo 8 palabras por tarjeta; máximo 2 tarjetas simultáneas.
TipografíaSans serif limpia; título 64–72 px; etiqueta 40–48 px; fórmula 52–60 px.
PosiciónMargen seguro de 8%; nunca sobre fondos ocupados; reservar una placa clara cuando sea necesario.
EntradaFade y desplazamiento suave de 500–700 ms; aparece cuando la voz nombra la idea.
SalidaFade de 350–500 ms antes del siguiente concepto.
ProhibidoSubtítulos automáticos, texto decorativo, letras dentro de imágenes, cifras inventadas y etiquetas no listadas.
ValidaciónComparar cada cadena renderizada con su cadena fuente antes de aprobar la escena.

4. Mensaje 1 para HeyGen: reglas globales

Enviar mediante heygen_interactive_session, con orientation=landscape y auto_proceed=false. No renderizar todavía.

Crea un documental educativo en español internacional titulado “The God Equation”.
Audiencia: estudiantes de high school, aproximadamente de 14 a 18 años.
Duración objetivo: 13:30 a 14:30. Formato 16:9, 1080p.

OBJETIVO
Explica ideas difíciles con palabras sencillas y ejemplos visuales. El estudiante no necesita saber física, biología o estadística antes de ver el video. Define cada término nuevo antes de usarlo. Usa oraciones cortas, tono natural y preguntas que despierten curiosidad. No suenes como conferencia universitaria, anuncio ni sermón.

PRESENTACIÓN
Documental sin avatar. Usa solo voz en off. No muestres presentador, rostro parlante ni persona mirando a cámara. La voz debe sonar serena, profunda, clara y segura; como un excelente maestro que disfruta explicar. Haz pausas breves después de cada idea importante. En la narración hablada usa la grafía “Balles” para obtener la pronunciación deseada. Conserva la notación científica visible como “BF”.

ESTRUCTURA PEDAGÓGICA
Cada escena debe seguir este orden:
1. Una pregunta sencilla.
2. Un ejemplo fácil de reconocer.
3. Un cambio visible en la animación.
4. Una frase corta para recordar.
Nunca uses una galaxia, una red o partículas solo porque se ven científicas. Cada objeto debe cumplir una función en la explicación.

CGI 2D
Usa gráficos vectoriales 2D hechos con Hyperframes para fórmulas, diagramas, tablas, etiquetas y curvas. Usa SVG y GSAP para animaciones exactas. Muestra relaciones paso a paso. No reveles todos los elementos al mismo tiempo.

CGI 3D
Cuando una escena necesite profundidad real, iluminación o movimiento de cámara, construye la escena en Three.js mediante el adapter de Hyperframes. Usa 3D para recorrer espacios, células, paisajes de posibilidades o atractores. Usa materiales suaves, luz de estudio, sombras naturales y cámara lenta. No uses 3D como adorno.

TEXTO EN PANTALLA
Todo texto visible debe crearse como HTML o SVG nativo de Hyperframes. Nunca generes letras dentro de una imagen o video sintético. Solo muestra las cadenas indicadas después de “TEXTO EXACTO”. Cópialas carácter por carácter. No agregues, traduzcas, reformules ni inventes palabras, cifras, fórmulas, subtítulos, logos o etiquetas.
Máximo 8 palabras por tarjeta y máximo 2 tarjetas a la vez. Usa sans serif limpia; títulos de 64 a 72 px; etiquetas de 40 a 48 px; fórmulas de 52 a 60 px. Mantén un margen seguro de 8%. No pongas texto sobre fondos ocupados. Hazlo entrar con fade y desplazamiento suave de 500 a 700 ms, sincronizado con la voz. Retíralo antes de presentar una nueva idea.

ESTILO
“Libro de ciencias que cobra vida”. Fondo pergamino #F7F5ED, tinta #2C3E50, salvia #5F7A6B, azul #3B5A8A, oro #A67C00, violeta #6D5E8A y terracota #B5651D. Combina ilustración científica clara, acuarela suave, diagramas modernos y CGI 3D sobrio. Transiciones con líneas que conectan ideas, tinta que se transforma y match cuts de escala. Evita glitches, fondos negros, exceso de brillos, ciencia ficción genérica, templos, halos, ojos místicos y símbolos religiosos.

MÚSICA
Cello, piano y textura ambiental muy suaves. Baja la música durante definiciones, fórmulas y conclusiones. La voz siempre debe escucharse con claridad.

FLUJO
Trabaja en modo interactivo. No renderices todavía. Confirma estas reglas y pide el segundo mensaje con el guion. Después prepara un storyboard de 16 escenas. Para cada escena indica: idea, animación 2D o 3D, cambio visible, texto exacto y criterio de aceptación. Espera mi aprobación.

5. Mensaje 2: guion sencillo y contratos de escena

Usa este guion literalmente. No cambies las afirmaciones. Las indicaciones visuales no forman parte de la narración.

ESCENA 1 — UN UNIVERSO LLENO DE PATRONES
NARRACIÓN: “Mira a tu alrededor. Una galaxia, una célula y tu cerebro parecen muy diferentes. Pero los tres siguen patrones. La ciencia usa la palabra información para hablar de relaciones que organizan algo. Este video hace una pregunta: ¿de dónde viene tanto orden?”
VISUAL: CGI 2D. Galaxia, célula y neurona aparecen por separado. Líneas simples muestran patrones compartidos y convergen en una tarjeta central.
TEXTO EXACTO: “INFORMACIÓN = RELACIONES CON ORDEN”
ACEPTACIÓN: se entiende que información significa organización, no archivos digitales.

ESCENA 2 — DOS EXPLICACIONES
NARRACIÓN: “Imagina dos detectives frente a las mismas pistas. Uno piensa que el orden tiene una fuente. El otro piensa que surgió sin una mente previa. No elegimos por gusto. Preguntamos cuál explicación esperaba mejor cada pista.”
VISUAL: CGI 2D. Una misma caja de pistas alimenta dos modelos. Cada modelo crea una predicción distinta. No mostrar personas ni combate.
TEXTO EXACTO: “HIPÓTESIS → PREDICCIÓN → PISTA”
ACEPTACIÓN: las dos hipótesis se comparan con la misma evidencia.

ESCENA 3 — LA IDEA DE BALLES
NARRACIÓN: “Balles nos ayuda a comparar esas explicaciones. Hacemos una pregunta sencilla: si una hipótesis fuera cierta, ¿qué tan probable sería encontrar esta pista? Después hacemos la misma pregunta para la otra hipótesis.”
VISUAL: CGI 2D. Una pista entra en dos máquinas transparentes. Cada máquina muestra una barra de probabilidad distinta. Después aparece la fórmula correcta.
TEXTO EXACTO 1: “¿QUÉ HIPÓTESIS ESPERABA MEJOR LA PISTA?”
TEXTO EXACTO 2: “BF = P(D|H₁) / P(D|H₀)”
ACEPTACIÓN: fórmula exacta y explicación visual sin números inventados.

ESCENA 4 — ANTES Y DESPUÉS DE UNA PISTA
NARRACIÓN: “Antes de ver una pista, ya tenemos una idea inicial. Se llama prior. Cuando llega evidencia nueva, actualizamos esa idea. El resultado se llama posterior. Distintos puntos de partida pueden terminar en resultados distintos.”
VISUAL: CGI 2D. Tres fichas empiezan en lugares diferentes, reciben la misma evidencia y avanzan hacia nuevos puntos.
TEXTO EXACTO 1: “PRIOR = ANTES DE LA PISTA”
TEXTO EXACTO 2: “POSTERIOR = DESPUÉS DE LA PISTA”
ACEPTACIÓN: el movimiento deja clara la actualización.

ESCENA 5 — UN UNIVERSO MUY SENSIBLE
NARRACIÓN: “Algunas constantes de la física parecen estar dentro de rangos especiales. Si cambian demasiado, no hay estrellas estables, átomos complejos o química como la nuestra. Esto no prueba diseño. Nos obliga a comparar varias explicaciones.”
VISUAL: CGI 3D en Three.js mediante el adapter. Un panel cambia una constante y el sistema pasa de estable a inestable. Luego aparecen tres caminos explicativos equivalentes.
TEXTO EXACTO: “AJUSTE FINO: COMPARAR EXPLICACIONES”
ACEPTACIÓN: mostrar sensibilidad sin un dial mágico ni un ganador automático.

ESCENA 6 — CÓMO LAS CÉLULAS CONSTRUYEN UNA FORMA
NARRACIÓN: “Tus genes son importantes, pero las células también necesitan coordinarse. Usan señales químicas y eléctricas para decidir qué hacer y dónde hacerlo. Como un equipo que comparte un plano, muchas células pueden construir una forma completa.”
VISUAL: CGI 2D y 3D. Células reciben pulsos bioeléctricos, cambian su conducta local y forman un tejido organizado.
TEXTO EXACTO: “SEÑALES LOCALES → FORMA GLOBAL”
ACEPTACIÓN: genes, señales y anatomía aparecen como partes complementarias.

ESCENA 7 — EL MISTERIO DE LA CONSCIENCIA
NARRACIÓN: “Sabemos que el cerebro y la experiencia están conectados. Pero todavía discutimos cómo la actividad cerebral se convierte en lo que sentimos. Existen varias ideas. Algunas son fuertes. Otras, como la mente transmisiva, siguen siendo especulativas.”
VISUAL: CGI 2D. Cerebro y experiencia conectados; tres modelos rivales quedan abiertos. El modelo transmisivo aparece con borde violeta.
TEXTO EXACTO 1: “PROBLEMA ABIERTO”
TEXTO EXACTO 2: “HIPÓTESIS TRANSMISIVA: ESPECULATIVA”
ACEPTACIÓN: no presentar una conjetura como hecho.

ESCENA 8 — LA EVIDENCIA TAMBIÉN PUEDE RESTAR
NARRACIÓN: “Un buen modelo no cuenta solo las pistas que le ayudan. El sentido moral puede apoyar una fuente de valor. El sufrimiento injusto puede contar en contra. Si una pista perjudica la hipótesis, el cálculo debe mostrarlo.”
VISUAL: CGI 2D. Una balanza recibe una ficha favorable y después una adversa; la probabilidad sube y luego baja.
TEXTO EXACTO: “EVIDENCIA A FAVOR Y EN CONTRA”
ACEPTACIÓN: la evidencia adversa reduce claramente el resultado.

ESCENA 9 — NO CONTAR DOS VECES LA MISMA PISTA
NARRACIÓN: “Dos pistas pueden estar conectadas. Si las contamos como independientes, exageramos el resultado. Por eso agrupamos datos relacionados antes de combinarlos. Es como evitar que el mismo testigo vote dos veces.”
VISUAL: CGI 2D. Nodos conectados se agrupan en una sola tarjeta antes de entrar al cálculo.
TEXTO EXACTO: “CORRELACIÓN: EVITAR DOBLE CONTEO”
ACEPTACIÓN: mostrar por qué agrupar cambia el resultado.

ESCENA 10 — UN MAPA DE FORMAS POSIBLES
NARRACIÓN: “Imagina un mapa con muchas formas posibles. Un sistema físico no puede llegar a todas. Sus reglas abren ciertos caminos y cierran otros. Algunos destinos son atractores: estados a los que el sistema tiende a regresar.”
VISUAL: CGI 3D en Three.js mediante el adapter. La cámara recorre un paisaje de caminos; varias trayectorias convergen en dos valles atractores.
TEXTO EXACTO: “ATRACTOR = ESTADO ESTABLE”
ACEPTACIÓN: posibilidad, camino y estado estable deben verse en orden.

ESCENA 11 — ORDENADO SEGÚN RELACIONES
NARRACIÓN: “Decir que algo sigue matemáticas no significa que esté hecho de números. Una cuerda, una órbita y una forma viva pueden compartir proporciones. Los números describen relaciones que se repiten en sistemas diferentes.”
VISUAL: CGI 2D. Cuerda vibrante, órbita y forma biológica se alinean mediante una misma proporción gráfica.
TEXTO EXACTO: “ORDENADO SEGÚN RELACIONES”
ACEPTACIÓN: mostrar proporción, no numerología.

ESCENA 12 — PREDECIR, COMPARAR Y ACTUAR
NARRACIÓN: “Un organismo intenta anticipar lo que sentirá. Compara su predicción con lo que ocurre. Si hay una diferencia, aprende o actúa. El Principio de Energía Libre estudia este ciclo con matemáticas.”
VISUAL: CGI 2D. Ciclo paso a paso: predicción, sensación, error, acción y nueva sensación. El error disminuye al final.
TEXTO EXACTO: “PREDECIR → COMPARAR → ACTUAR”
ACEPTACIÓN: no confundir energía libre con combustible físico.

ESCENA 13 — ¿QUÉ PODRÍA MOSTRAR QUE ESTAMOS EQUIVOCADOS?
NARRACIÓN: “Una idea científica debe correr riesgos. Si otra explicación predice mejor los datos, nuestra hipótesis pierde fuerza. Si nunca puede perder, tampoco puede enseñarnos mucho. Por eso definimos pruebas que podrían cambiar nuestra conclusión.”
VISUAL: CGI 2D. Tres pruebas se dividen en resultado favorable y resultado adverso; ambos caminos permanecen visibles.
TEXTO EXACTO: “UNA BUENA HIPÓTESIS PUEDE PERDER”
ACEPTACIÓN: mostrar condiciones reales de debilitamiento.

ESCENA 14 — UNA OPERACIÓN QUE SE REPITE
NARRACIÓN: “En física, biología, aprendizaje y computación aparece una idea parecida: muchas posibilidades, una restricción y un resultado estable. En este libro, Logos es el nombre de una posible fuente común de esas restricciones.”
VISUAL: Cuatro paneles CGI 2D ejecutan sincronizados posibilidades → restricción → resultado. No usar iconos religiosos.
TEXTO EXACTO: “POSIBILIDADES → RESTRICCIÓN → RESULTADO”
ACEPTACIÓN: la unidad surge de la operación compartida.

ESCENA 15 — UN MODELO ABIERTO A CRÍTICA
NARRACIÓN: “La ciencia no demuestra aquí a una deidad personal. Compara una hipótesis informacional con alternativas. Los números pueden discutirse. El punto de partida importa. Las pistas pueden estar conectadas. El valor del modelo es mostrar todas esas decisiones.”
VISUAL: CGI 2D. Tablero claro con cuatro tarjetas: factores, prior, dependencias y sensibilidad.
TEXTO EXACTO: “VISIBLE, DISCUTIBLE, REVISABLE”
ACEPTACIÓN: no mostrar porcentaje final triunfal.

ESCENA 16 — LA PREGUNTA SIGUE ABIERTA
NARRACIÓN: “The God Equation propone una forma de investigar. Medir patrones. Comparar explicaciones. Mostrar la incertidumbre. Y cambiar de opinión cuando llegue mejor evidencia. Si el universo puede leerse como información, nuestra tarea no es venerarlo. Es comprenderlo.”
VISUAL: Los elementos de la primera escena regresan conectados por relaciones comprensibles. Cierre limpio con el título.
TEXTO EXACTO 1: “THE GOD EQUATION”
TEXTO EXACTO 2: “UNA HIPÓTESIS ABIERTA A PRUEBA”
ACEPTACIÓN: cierre científico, claro y no religioso.

Antes de renderizar, entrega el storyboard completo. Marca cualquier texto, fórmula o visual que no puedas producir exactamente. No sustituyas una escena difícil con imágenes genéricas.

6. Control de calidad antes del render

PruebaAprobaciónRechazo
ComprensiónUn estudiante puede explicar la idea con sus palabras.Requiere conocimientos universitarios no explicados.
AlineaciónLa animación demuestra la frase narrada.El visual solo comparte el tema.
TextoCoincide carácter por carácter con TEXTO EXACTO.Cualquier palabra añadida, omitida o mal escrita.
2D/3DLa técnica elegida ayuda a comprender.3D ornamental o diagrama plano cuando se necesita profundidad.
RitmoPregunta, cambio y conclusión tienen tiempo para entenderse.Revelación simultánea, loop o corte antes de comprender.
CertezaHipótesis, evidencia y especulación se distinguen.Una idea debatida parece un hecho.
AudioFrases respirables, pausas y términos pronunciados correctamente.Lectura corrida o tono promocional.
