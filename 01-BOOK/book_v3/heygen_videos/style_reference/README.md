# Biblia de estilo — Serie The God Equation (aprobada por el usuario 2026-10-15)

Estilo oficial: **códice académico antiguo** — manuscrito ilustrado, grabado a
aguafuerte + acuarela sobre pergamino envejecido (atlas científico s.XIX /
cuaderno tipo Da Vinci). Referencias visuales aportadas por el usuario:
`codex_ref_01.jpg` … `codex_ref_05.jpg`.
