```diff
                 Trayectoria óptima:
                 Semana 1: NO tratar (precio bajo)

                 Semana 3: Cosecha máxima (IPF 0.92 + precio $22 = máximo VEP)
                 
                 Resultado: VEP $56,300 vs $52,400 (alternativa de tratar ahora)"
```

**Algoritmo (pseudocódigo):**

```python
@router.post("/api/v1/platonic/goal-directed-action")
async def get_goal_directed_recommendation(request: GoalRequest):
    """
    Retorna acción recomendada basada en navegación hacia goal pattern,
    NO en estado actual aislado.
    """
    # 1. Usuario selecciona goal pattern
    goal = request.goal_pattern  # "VEP_optimal", "cost_min", "ipf_max"
    current_state = request.current_state
    
    # 2. Calcular trayectoria óptima hacia goal (8 semanas)
    optimal_trajectory = compute_optimal_path(
        current_state=current_state,
        goal_pattern=goal,
        farm_kernel=farm_kernel,
        horizon=8,
    )
    
    # 3. Extraer acción AHORA (primer paso de trayectoria)
    recommended_action = optimal_trajectory.actions[0]
    
    # 4. Generar explicación en contexto del goal
    explanation = generate_narrative(
        action=recommended_action,
        trajectory=optimal_trajectory,
        goal=goal,
        current_state=current_state,
    )
    
    # 5. Proyectar futuro (próximas 3 semanas)
    future_actions = optimal_trajectory.actions[1:4]
    expected_vep = optimal_trajectory.final_state.vep
    
    return {
        'goal_pattern': goal,
        'recommended_action_now': recommended_action,
        'action_rationale': explanation,
        'future_actions': future_actions,
        'expected_vep_at_goal': expected_vep,
        'confidence_score': calculate_confidence(optimal_trajectory),
    }
```
